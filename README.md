# ちんちらクエスト

チンチラを主人公にした、昔ながらの2DコマンドバトルRPG(ドラクエ/ポケモン風)。
ビルド不要のHTML/CSS/JSのみで動作し、GitHub Pagesで公開する。

- 公開URL: https://fantianhesha918-star.github.io/chinchilla-quest/
- 公開元: `docs/` フォルダ(GitHub Pages)

## 遊び方

- タイトル画面で「つづきから」(セーブ済みスロットを選んで再開)・「さいしょから」(スロットを選んで
  新規開始、データが入っているスロットを選んだ場合は上書き確認あり)を選択。セーブは3スロットまで
  (スロットごとに名前・Lv・最終プレイ日時を表示)。ゲーム中はメニューの「タイトルへもどる」で
  いつでもタイトルに戻り、別スロットを選び直せる
- セレクトボタンのメニューは「ステータス/わざ/どうぐ/なかま/バッジ/ずかん/タイトルへもどる」の
  カテゴリ選択画面(1画面あたりの情報量を減らすため2026-07-30に全項目を1枚に並べる構成から変更)。
  各カテゴリをタップすると該当画面だけが表示され、「← もどる」でカテゴリ選択に戻る。わざ・なかま・
  バッジのボタンには件数(習得数/編成数・獲得バッジ数)を表示。どうぐ画面でアイテムを使っても
  カテゴリ選択には戻らず、その場で一覧が更新される
- スターター選択(グレーチンチラ、しろは近日公開)→ 名前入力 → フィールド開始
- 画面下部のD-padでマス目移動。草むらでランダムエンカウント、NPCに隣接して「はなす」で会話。
  キーボードにも対応(矢印キー/WASDで移動、Enter・スペース・Zで「はなす」/会話送り、Escape・Xで
  メニューや会話を閉じる)。名前入力欄にフォーカス中は移動キーを奪わない
- 移動は1マスごとに150ms・等速(linear)でスライドし、キー/ボタン連打も同じ間隔でスロットルされる
  ため、押しっぱなしでも一定のテンポで歩き続ける(2026-07-30〜。それまでは押した回数ぶん即座に
  座標が進み、アニメーションが追いつかず「マス目を飛ぶ」ような見た目だった)。あわせてスライド中に
  歩行アニメーションのフレームを1回切り替え、足が動いて見えるようにしている
- 戦闘画面には敵味方それぞれが呼吸するように上下バウンドする待機モーションがあり、位相をずらして
  同時に跳ねないようにしている(会心・被弾シェイクや戦闘不能演出とは独立、それらの間は一時停止)。
  マップに応じた専用の戦闘背景(しばふの草原=草むら、コケむした洞窟=洞窟、こおりの尾根=雪原)も
  表示され、それ以外のマップ(たそがれの荒野・だいまどうしの塔・奥津宮の霊域)は現状 従来どおりの
  無地グラデーション背景のまま(専用イラスト未用意)
- 戦闘は「バトル場に出ている1体」だけが行動する単体バトラー制(ポケモン風)。主人公となかま
  (メニューの「なかま」欄から編成した最大3体)をあわせた手持ち全員が入れ替え候補で、主人公自身も
  控えに回したり、また前に出したりできる。コマンドは わざ/アイテム/いれかえ/にげる の4つ
  (「たたかう」という固定コマンドは無く、たいあたりも わざの1つとして選ぶ)
  - **わざ**: 場に出ているモンスターが覚えている技(たいあたり・すなかけ など)の一覧から選んで攻撃。
    低確率で会心の一撃が発生(通常の1.8倍のダメージ)
  - **アイテム**: きずぐすり/マナのしずくは、その時 場に出ているモンスターのHP/MPを回復する。
    なかまボール系は野生モンスターに投げて捕獲(下記)
  - **いれかえ**: 手持ちの生存メンバーと交代。交代した直後は同じターン内で そのままそのモンスターの
    行動を選べる(交代だけではターンを消費しない)
  - **にげる**: 現在 場に出ているモンスターのすばやさで成功率を判定(ボス戦は使用不可)
  - 場に出ているモンスターのHPが0になると、手持ちから次に出すモンスターを選ぶ画面になる
    (このときは選ぶだけでそのターンの行動はできない)。手持ち全員(主人公+なかま全員)が
    倒れると敗北し、村へ運ばれる
  - なかまのHP/MPは主人公と同じく戦闘をまたいで保持される(いやしの泉やアイテムで回復するまで
    そのまま)。次の戦闘で誰を先頭に出すかは、メニューの「なかま」欄でいつでも指定できる
    (主人公・なかま各カードの「リーダーにする」ボタン。戦闘中に「いれかえ」で交代した場合も
    その選択が引き継がれる)。指定した先頭メンバーが倒れている場合は自動的に生存している
    メンバーが代わりに出る(主人公が戦闘不能のまま次の戦闘に出てしまう不具合を修正)
- 属性システム(ほのお/みず/くさ/かぜ/つち/でんき/てん/やみ/まほう/けもの の10属性 + 無属性)。属性ごとに
  「強い相手」1つ・「弱い相手」1つが決まっており(例: ほのお→くさに2倍、ほのお→みずには0.5倍)、
  それ以外の相手には等倍。有利な技を当てると専用エフェクトと「こうかは ばつぐんだ!」が表示される。
  敵の名前・わざ一覧・ずかん詳細には色分けされた属性アイコン(バッジ)が表示され、相性がひと目で分かる
- なかまは自分の属性に応じたわざを初級→中級→上級→特級の順にレベルアップで習得していく
  (属性ごとに専用のわざを約17〜20個ずつ用意、`COMPANION_SKILL_TRACKS`で管理)
- レベルアップ時はHP/MP/こうげき/ぼうぎょ/すばやさの上昇量を表示。あわせてHP/MPを全回復する
  (2026-07-30〜。それまでは最大値の上昇分だけ回復する仕様だった)。主人公・なかま(パーティ編成中の
  全員)どちらも対象
- どうぐの「チモシーボール」系を野生のモンスターに投げると、確率で なかまにできる(ボスには使用不可、
  HPが低いほど成功率アップ)。チモシーボール(×1.0)・スーパー(×1.5)・ハイパー(×2.0)・
  マスター(必ず成功)の4種類があり、ショップで購入できる
- パーティに編成中のなかまは、戦闘に出ていた・いないに関わらず勝利するたびに主人公と同じ経験値を
  もらってレベルアップし、HP/MP/こうげき/ぼうぎょ/すばやさが少しずつ強くなる(種族ごとにレベルを
  個別管理、メニュー・戦闘画面にLv表示)。主人公と同じくMPを持ち、レベルアップで自分の属性に
  あったわざを覚えていく(例: つち属性なら すなかけ、ほのお属性なら ほのおのつぶて)。
  一定レベルに達すると なかまも自動で進化する(下記)
- Lv8で進化ルートを選択(なかよし系/たくましい系)。以降は該当ルートに沿って自動進化し、進化する
  たびに専用のわざを1つ習得する
- マップ上を歩く姿と戦闘中の姿は別物(2026-07-30〜)。マップは進化段階によらず常に主人公「チモ」の
  歩行ドット絵(4方向×4コマ、`docs/assets/hero/walk_*.webp`)で、戦闘・メニューのなかまカードは
  進化後の姿を表示する。設定上は「プレイヤー(トレーナー)が操作するチモが、戦闘では進化後の姿で
  戦う」という位置づけ
- メニューの「ずかん」で発見済みモンスターの一覧・ステータスを確認できる(未発見は「？？？」の
  シルエット表示)。野生モンスターと出会う、またはなかまが進化することで自動的に発見済みになる
- 村のショップできずぐすり・マナのしずくを購入可能
- フィールド・ダンジョンにたからばこを設置。乗ると自動で開き、コインやアイテムを入手(一度開けたら消える)
- ダンジョン奥のボス「ようがんゴーレム」(Lv16)を倒すと道が開け、以降「こおりの尾根」→
  「たそがれの荒野」→「だいまどうしの塔」→「魔の回廊」の4マップを順に進める。各マップの奥には
  それぞれ中間ボス「ゆきおとこ」(Lv21)・「おにおう」(Lv25)・「まじんまどうし」(Lv28)・
  「あくま」(Lv32)が待ち構えており、倒すたびに次のマップへの道が開く(未撃破のうちは同じマスに
  乗ると何度でも再戦になる)。各マップの野生エンカウントには進化後のなかま種族(フィールド/
  ダンジョン系の中〜上位進化形)が配置されており、レベルなりに足慣らしをしながら奥へ進める設計に
  なっている。最後の「あくま」を倒すと隠しエリア「奥津宮の霊域」への入り口が開く(以降いつでも
  行き来できる)。霊域では伝説・神獣・古代・神の上位ティアモンスター(計33種)が出現し、
  すべてなかまボールで捕獲可能(通常のフィールド/ダンジョンより捕獲成功率は低め。マスターボールは
  この補正を無視して必ず成功)
- ボス(計12体、下記参照)を倒すと、専用の強力なわざを1つ習得し、HP/MP/こうげき/ぼうぎょ/すばやさの
  いずれかが永続的に上昇し、そのボスの「バッジ」を1つ手に入れる。バッジはメニュー内の専用欄で
  獲得数(n / 12)とあわせて確認できる(ジムバッジ収集のような、ボス撃破の目印・達成感を示す要素)

## 村からの三方向ルートと四天王

村は南(しばふの草原方面、上記の一本道)に加えて、北・西・東の3方向にもルートが伸びている。
北・西・東の壁は最初は大きな岩(`obstacle_rock1.webp`)でふさがれていて進めず、指定のボスを
倒すと該当の壁が開いた見た目に変わり、実際に通行・ワープできるようになる(`gatedExits`という
汎用の「特定ボス撃破で開通するワープ」の仕組みで実装。村に限らずどのマップでも使える)。

- **解放順序(一本道)**: 南ルート最終ボス「あくま」撃退 → 北ルート解放 → 北ルート最終ボス
  「ドラゴン」(Lv34)撃退 → 西ルート解放 → 西ルート最終ボス「まひとつ目王」(Lv38)撃退 →
  東ルート解放 → 東ルート最終ボス「幽霊王」(Lv42)撃退 → 奥津宮の霊域内に「してんのうの間」への
  扉が開く
- 北・西・東の各ルートはいずれも2体のボスを配置。1体目の「ばんにん」は既存モンスター(こだい
  ゴーレム/デスライダー/あんこくきしおう)をそのまま流用した強敵版(新規イラスト不要、同じ
  モンスターの「ボス版」として再登場する形)、2体目がそのルートの signature boss(ドラゴン/
  まひとつ目王/幽霊王、いずれも温存していた上級イラストを使用)
- 「してんのうの間」は奥津宮の霊域の奥にある隠し部屋(北の壁が開通、東ルートの幽霊王撃破が条件)。
  一本道の細い回廊に、これまでの主要ボス4体(ようがんゴーレム・ゆきおとこ・おにおう・
  まじんまどうし)のリベンジ版(同じイラストのまま、Lv45〜52・大幅強化ステータスで再登場、
  それぞれ専用の強力なわざ・バッジを新たに獲得)が順番に立ちはだかる、既存ボスを再利用した
  最終チャレンジコンテンツ。踏破後にたからばこ(💰500)を設置

## NPCヒントと鍵の仕掛け

これまでNPCが1体もいなかった9マップ(しばふの草原・コケむした洞窟・こおりの尾根・たそがれの荒野・
だいまどうしの塔・魔の回廊・北/西/東ルート)に、それぞれヒントNPCを1体ずつ配置した。多くは
「この先のボスは◯◯属性で、△△属性のわざが弱点らしい」という、実際の属性相性表(`ELEMENTS`)と
一致する正確なヒントを話す(推測や誤った情報ではなく、事前に相性を確認したうえで書いている)。

村を含む一部のマップには、「特定のカギを持っていないと通れない扉」も設置した(`gatedExits`の
`requiresItem`で判定、ボス撃退で開く扉と同じ仕組みを流用)。カギは以下の2種類、どちらも
軽い探索・NPCとの会話だけで入手できる(戦闘や複雑な謎解きは不要):

- **ふるいカギ**: しばふの草原のたからばこ(11,3)で入手。村の北壁のすきま(11,0)にある
  隠し扉を開けると「村の隠し部屋」に入れ、たからばこからハイパーチモシーボールが手に入る
- **ちかみちのカギ**: コケむした洞窟のNPC「まよえるぼうけんしゃ」(9,1)に話しかけると
  もらえる(初回のみ。会話するとその場でアイテムを1つ渡す仕組み `givesItem` を新設)。
  洞窟内の隠し扉(12,5)を開けると「ダンジョンの隠し部屋」に入れ、たからばこから
  💰200が手に入る

カギ・隠し部屋はどちらも小規模な寄り道要素で、メインの攻略には必須ではない。

## アイテムの拡充

道具アイテムを3種類追加し、入手手段のバリエーションを増やした(イラストは素材フォルダの
「アイテムのイラスト.png」から切り出し・背景透過処理して使用):

- **ハイポーション**(HP60回復・ショップで55コイン): きずぐすりの上位互換
- **せいれいのけっしょう**(MP35回復・ショップで70コイン): マナのしずくの上位互換
- **エリクサー**(HP・MPを全回復): ショップでは売っていない貴重品。宝箱・ボス撃破報酬のみで入手可能

入手ルートは以下の4系統:

- **ショップ**: ハイポーション・せいれいのけっしょうを購入可能(エリクサーは非売品)
- **たからばこ**: これまで宝箱が無かった7マップ(こおりの尾根・たそがれの荒野・だいまどうしの塔・
  魔の回廊・北/西/東ルート)にそれぞれ1つずつ新設。北/西/東ルートの3つはエリクサーが手に入る
- **NPCから**: 「こおりの狩人」「さすらいの魔導師」がヒント会話の初回にハイポーション/
  せいれいのけっしょうを1つ渡してくれる(`givesItem`の仕組みを流用)
- **ボス撃破時**: ストーリーボス8体は撃破時にハイポーションかせいれいのけっしょうを2個、
  四天王4体はエリクサーを1個、バッジ・わざ習得と同時に手に入る(`BOSS_REWARDS`に`itemId`/
  `itemAmount`を追加、初回撃破時のみ付与)

エリクサーの「HP・MP全回復」は既存の`kind: "hp"`/`"mp"`に加えて新設した`kind: "full"`で実装。
道具の使用可否リストも、ショップの販売リスト(`SHOP_ITEM_IDS`)と使用可能リスト
(`USABLE_ITEM_IDS`)を分離し、非売品でも所持していれば戦闘中・フィールドメニューの
どちらからも使えるようにした。

## わざを覚えるペレット

10属性それぞれの「ペレット」(ショップで150コインで購入可能、全10種)を追加。食べると
その属性のわざを1つ覚える、TM(わざマシン)のような道具。アイコンは属性バッジ
(`assets/icons/elem_*.webp`)を流用し、新規アセット作成なしで実装した。

習得ルールは対象によって異なる:

- **主人公**: 属性の縛りなし。どのペレットでも食べられる(伝説級のなかまが使う属性でも制限なし)
- **なかま**: 自分と同じ属性のペレットしか食べられない(例: ほのお属性のなかまは、ほのおのペレット
  以外を食べようとすると「たべられない」と拒否され、道具も消費されない)

主人公はフィールドメニューからいつでも使える(常に主人公が対象)。なかまに食べさせたい場合は
戦闘中にそのなかまを控えバトラーではなく「アクティブ」な状態にしてから、戦闘中のアイテム欄
から「たべる」を選ぶ(通常の道具と同じ、いまアクティブなバトラーが対象になる仕組みをそのまま
流用)。覚えるわざは各属性のわざツリー(`fire3_1`など、中級と上級の間にあたる3段目の技、
威力56/MP13)で統一。すでに覚えているわざの場合は「もう おぼえている」と表示され、
道具は消費されない。

## レベルアップ演出

戦闘中にレベルアップした瞬間、メッセージだけでなく専用の演出が入るようにした:
戦闘フィールド全体に金色の光がフラッシュし(`levelup-flash`)、いまアクティブなバトラーの
スプライトが一瞬明るく光って拡大し(`levelup-glow`)、中央に「LEVEL UP!」のバナーが
ポップして消える(`levelup-banner`)。主人公・なかまどちらのレベルアップでも発生する。

実装は`playSequence`のメッセージ行を文字列だけでなく`{text, effect}`形式でも渡せるように
拡張し、「レベルアップ! Lv◯ になった!」の行が表示される瞬間に`triggerLevelUpEffect()`を
呼ぶ形にした(会心の一撃演出`shake-crit`/`crit-flash`と同じ、CSSクラスの一時付与+
`setTimeout`で除去する方式)。

## わざの命中演出(踏み込み・弾)

技を出したときに「予備動作→着弾」の間を作り、当たった瞬間の重みを出すようにした:

- **属性ありの技**(ほのお・みず・くさ等10属性): 既存の属性エフェクト画像
  (`assets/effects/effect_*.webp`、ダメージ演出`showElementEffect`で使っていたもの)を
  そのまま弾として再利用し、攻撃側から相手側へ実際に画面上を飛んでいく
  (`playProjectileAnim`、攻撃側/相手側スプライトの`getBoundingClientRect()`から
  始点・終点を計算し、`left`/`top`のCSSトランジションで移動、飛びながら拡大+回転)。
  着弾した瞬間に弾を消して、そこから先は元々の被弾シェイク/ダメージポップ/
  属性エフェクトのポップが続けて再生される。10属性ぶんの画像が既にあったので、
  新規アセット追加なしで全属性に対応できた。
- **無属性の技**(たいあたり・ずつきなど): 弾を飛ばす画像が無いので、代わりに
  攻撃側スプライトが相手に向かって軽く踏み込んで戻るモーション(`playAttackAnim`、
  `attack-lunge`)を再生する。
- **会心の一撃**: 元々あった`crit-flash`(画面フラッシュ)の`field-shake`キーフレームに
  ズームパンチ(`scale`)を追加し、当たった瞬間に画面全体が一瞬拡大して衝撃を強調するようにした。
- 通常ヒットの被弾シェイク(`battle-shake`/`battle-shake-crit`)にも一瞬の明滅
  (`filter: brightness()`)を足し、「ダメージを受けた」感をどの技でも出せるようにした。

技のこの振り分け(`playMoveAnim`)は`sk.element`の有無だけで自動的に決まるので、
今後わざを追加するときも属性を設定するだけで弾演出が自動的に付く。

## 進化ルート

- **なかよし系(食べ物モチーフ)**: おやこどん → みょうが → ベーグル → やきにく → とうふ(最終形)
- **たくましい系**: いたち → かえる → かたつむり → しゃち → サイ(最終形)

進化イラストは「もちチンチラ育成」で作成した衣装イラストを再利用(透過処理済み)。
各進化段階で専用のわざを1つ習得する(例: たくましい系Lv8は「いたちスラッシュ」、Lv36の最終形
「サイ」は「サイクラッシュ」)。

## モンスター進化(なかま・野生共通)

フィールド9系統は3段階、ダンジョン9系統は2段階の進化系を実装。野生エンカウントには常に最初の
姿のみ出現し、なかまにしたあと一定レベルに達すると自動で進化する(見た目・ステータス・わざが
更新され、「◯◯は××にしんかした!」と表示)。捕獲時の内部データはリネームせず、都度いまの
レベルから見た目を動的に解決する方式のため、進化してもセーブデータの再編成は不要。

## 隠しエリアの上位ティアモンスター

ボス撃破後に解放される「奥津宮の霊域」(ダンジョン最奥、ボスがいたマスから行き来)専用のモンスター群。
素材シート4枚(伝説9体・神獣12体・古代12体・神6体、計39体の候補イラスト)から、モチーフの重複
(鳳凰・クジラ・東洋龍・似た衣装の神キャラなど)とゲームのトーンに合わないデザインを除いて
33体(古代12・神獣9・伝説8・神4)に厳選して採用。ティアが上がるほどレベル・ステータスが高く、
捕獲成功率(`MONSTERS`の`catchPenalty`、0.18〜0.6)も下がる。

## モンスター・主人公イラスト

主人公・敵キャラはすべてイラスト素材(初級9体=フィールド、中級9体=ダンジョン、上級8体=ボス、
隠しエリア33体=奥津宮の霊域)を使用。背景透過・進化系イラストの切り出しはPython(PIL+scipy)で
連結成分解析による自動処理(隣接キャラの映り込みを防ぐため、切り出し矩形ではなく連結成分ラベル
単位でマスクして透過)。隠しエリアの33体は元シートがグリッド整列済みのため、矩形クロップ+
白背景の連結領域を透過する簡易処理で対応。上級イラスト8体はすべて採用済み(ゆきおとこ・おにおう・
まじんまどうしは南ルートの中間ボス、あくまは南ルート最終ボス、ドラゴン・まひとつ目王・幽霊王は
北/西/東ルートの signature boss)。四天王(してんのうの間)はこの8体分の新規イラストを使わず、
既存の主要ボス4体(ようがんゴーレム・ゆきおとこ・おにおう・まじんまどうし)のイラストを
そのまま再利用したリベンジ版として実装した。

## セーブデータ

localStorageに3スロット分(`chinchilla-quest-save-v1-slot1`〜`slot3`)をJSONで保存。

スロット1へ移行する(移行後、旧キーは削除)。
