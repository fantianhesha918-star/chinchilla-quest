# ちんちらクエスト

チンチラを主人公にした、昔ながらの2DコマンドバトルRPG(ドラクエ/ポケモン風)。
ビルド不要のHTML/CSS/JSのみで動作し、GitHub Pagesで公開する。

- 公開URL: https://fantianhesha918-star.github.io/chinchilla-quest/
- 公開元: `docs/` フォルダ(GitHub Pages)

## 遊び方

- タイトル画面で「つづきから」(セーブ済みスロットを選んで再開)・「さいしょから」(スロットを選んで
  新規開始、データが入っているスロットを選んだ場合は上書き確認あり)を選択。セーブは3スロットまで
  (スロットごとに名前・Lv・最終プレイ日時を表示)。ゲーム中はメニューの「タイトルへもどる」で
  いつでもタイトルに戻り、別スロットを選び直せる
- スターター選択(グレーチンチラ、しろは近日公開)→ 名前入力 → フィールド開始
- 画面下部のD-padでマス目移動。草むらでランダムエンカウント、NPCに隣接して「はなす」で会話
- コマンドバトル(たたかう/わざ/どうぐ/にげる)。勝利で経験値・コインを獲得、レベルアップでわざを習得
  (低確率で会心の一撃が発生、通常の1.8倍のダメージ)
- 属性システム(ほのお/こおり/でんき/つち の4属性 + 無属性)。ほのお→つち→でんき→こおり→ほのお の順に
  有利(1.5倍・専用エフェクト表示)、逆順だと不利(0.7倍)。プレイヤーは「すなかけ」(つち)・
  「れんぞくアタック」(でんき)が対象、敵モンスターの一部にも属性を設定
- レベルアップ時はHP/MP/こうげき/ぼうぎょ/すばやさの上昇量を表示
- どうぐの「チモシーボール」系を野生のモンスターに投げると、確率で なかまにできる(ボスには使用不可、
  HPが低いほど成功率アップ)。チモシーボール(×1.0)・スーパー(×1.5)・ハイパー(×2.0)・
  マスター(必ず成功)の4種類があり、ショップで購入できる。なかまにしたモンスターはメニューの
  「なかま」欄から最大3体まで
  パーティに編成できる。戦闘では編成した中の1体だけが「せんとうよう」として場に出て、毎ターン
  「たたかう」(モンスター自身のステータス・わざ・属性で行動)か「いれかえ」(このターンは
  こうげきしない)を選択する方式(全員同時攻撃によるインフレを避けるため)
- パーティに編成中のなかまは、戦闘に出ていた・いないに関わらず勝利するたびに主人公と同じ経験値を
  もらってレベルアップし、HP/こうげき/ぼうぎょ/すばやさが少しずつ強くなる(種族ごとにレベルを
  個別管理、メニュー・戦闘画面にLv表示)。一定レベルに達すると なかまも自動で進化する(下記)
- Lv8で進化ルートを選択(なかよし系/たくましい系)。以降は該当ルートに沿って自動進化し、進化する
  たびに専用のわざを1つ習得する
- メニューの「ずかん」で発見済みモンスターの一覧・ステータスを確認できる(未発見は「？？？」の
  シルエット表示)。野生モンスターと出会う、またはなかまが進化することで自動的に発見済みになる
- 村のショップできずぐすり・マナのしずくを購入可能
- フィールド・ダンジョンにたからばこを設置。乗ると自動で開き、コインやアイテムを入手(一度開けたら消える)
- ダンジョン奥のボス「ようがんゴーレム」を倒すとクリア(にげる不可)

## 進化ルート

- **なかよし系(食べ物モチーフ)**: おやこどん → みょうが → ベーグル → やきにく → とうふ(最終形)
- **たくましい系**: いたち → かえる → かたつむり → しゃち → サイ(最終形)

進化イラストは「もちチンチラ育成」で作成した衣装イラストを再利用(透過処理済み)。
各進化段階で専用のわざを1つ習得する(例: たくましい系Lv8は「いたちスラッシュ」、Lv36の最終形
「サイ」は「サイクラッシュ」)。

## モンスター進化(なかま・野生共通)

フィールド9系統は3段階、ダンジョン9系統は2段階の進化系を実装。野生エンカウントには常に最初の
姿のみ出現し、なかまにしたあと一定レベルに達すると自動で進化する(見た目・ステータス・わざが
更新され、「◯◯は××にしんかした!」と表示)。捕獲時の内部データはリネームせず、都度いまの
レベルから見た目を動的に解決する方式のため、進化してもセーブデータの再編成は不要。

## モンスター・主人公イラスト

主人公・敵キャラはすべてイラスト素材(初級9体=フィールド、中級9体=ダンジョン、上級1体=ボス)を使用。
背景透過・進化系イラストの切り出しはPython(PIL+scipy)で連結成分解析による自動処理
(隣接キャラの映り込みを防ぐため、切り出し矩形ではなく連結成分ラベル単位でマスクして透過)。
上級イラストのうち「ようがんゴーレム」以外の8体(ドラゴン・魔人・鬼王など)は`docs/assets/monsters/`に
配置済みで、今後のボス追加・エリア拡張用に温存している。

## ファイル構成

- `docs/index.html` : 画面構造一式
- `docs/style.css` : スタイル
- `docs/data.js` : マップ・モンスター・わざ・アイテム・進化テーブルなどのゲームデータ
- `docs/app.js` : ゲームロジック本体(状態管理・移動・バトル・セーブ/ロード)
- `docs/assets/evolutions/*.webp` : 進化イラスト
- `docs/assets/monsters/*.webp` : モンスターイラスト(未使用の上級8体を含む)
- `docs/assets/hero/hero.webp` : 主人公(無進化時)のバトル用イラスト
- `docs/assets/hero/walk_*.webp` : 主人公(無進化時)のフィールド移動用ドット絵。下/左/右/上の4方向 ×
  各4コマの歩行アニメーションで、歩くたびにコマが切り替わる。進化後はこれまで通り進化イラストを
  使用(左向きは反転表示、アニメーションなし)
- `docs/assets/items/*.webp` : どうぐ・お金のアイコン(HUD/メニュー/ショップ/戦闘で使用)
- `docs/assets/npc/npc_herbalist.webp` : 村の追加NPC「くすし」
- `docs/assets/tiles/deco_well.webp` : 村の井戸(装飾、当たり判定なし)
- `docs/assets/tiles/deco_flowerbush.webp` : フィールドの花壇(装飾、当たり判定なし)
- `docs/assets/effects/effect_*.webp` : 属性攻撃時の演出(ほのお/こおり/でんき/つち)
- `docs/assets/tiles/tile_ground.webp` : フィールドの草むら床
- `docs/assets/tiles/tile_path.webp` : 村の通常床(石畳)

## セーブデータ

localStorageに3スロット分(`chinchilla-quest-save-v1-slot1`〜`slot3`)をJSONで保存。
旧バージョン(単一キー`chinchilla-quest-save-v1`)のセーブが残っている場合は、起動時に自動で
スロット1へ移行する(移行後、旧キーは削除)。
